BORDEREAU DE TRANSFERT · DÉMONSTRATION ÉTAPE 01 / 06
ÉTAPE 01 · 06

Qui expédie le pli ?

Renseignez la mission émettrice, son service et le référent responsable du bordereau.

Un moyen de contact professionnel est requis : téléphone ou courriel.

↳ Les coordonnées pourront être masquées dans le PDF.
ÉTAPE 02 · 06

À quelle mission est-il destiné ?

Indiquez la mission de destination et son contact autorisé. La confirmation d’autorisation est requise pour continuer.

Renseignez un moyen de contact professionnel.

ÉTAPE 03 · 06

Que contient le pli ?

Décrivez uniquement la catégorie générale, le nombre de pièces et le poids estimé. N’indiquez pas de contenu classifié ou détaillé.

Aucun détail confidentiel, identifiant, code ou description du contenu sensible.
ÉTAPE 04 · 06

Qui peut voir ces informations ?

Choisissez un repère de diffusion non secret et décidez quelles rubriques seront masquées dans le PDF.

Ces choix sont des repères de maquette, pas une classification officielle.
Saisissez uniquement une étiquette non secrète. Jamais de mot de passe, PIN, code de coffre ou identifiant d’accès.
Masquage dans le PDFFacultatif

Le récapitulatif de l’écran reste complet. Les rubriques choisies ci-dessous seront remplacées par « Masqué » dans le PDF.

ÉTAPE 05 · 06

Comment le pli sera-t-il acheminé ?

Précisez le mode prévu et un créneau d’enlèvement général, sans indiquer de procédure ou code de sécurité.

N’indiquez pas d’adresse sécurisée, d’itinéraire détaillé ou de consigne de sécurité.
ÉTAPE 06 · 06

Vérifiez, signez, exportez.

Relisez les informations et les règles de masquage. Le PDF sera généré au format A4.
